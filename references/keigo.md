# 敬語リファレンス

判断の軸は文化審議会「敬語の指針」（2007年）。敬語は「誤り」と「好みの問題」を分けて扱う。好みの問題を誤りとして直すと、書き手の意図や社内慣習を壊す。

## 1. 基本の三分類

- **尊敬語**：相手・第三者の動作を高める。いらっしゃる、おっしゃる、ご覧になる、召し上がる、お〜になる、ご〜になる、〜れる／られる
- **謙譲語**：自分の動作をへりくだり、相手を高める。伺う、申し上げる、拝見する、いただく、お〜する、ご〜する
- **丁寧語**：です・ます・ございます

いちばん多い誤りは、**相手の動作に謙譲語を使う**ことである。

| 誤り | 正しい形 |
|---|---|
| ご確認してください | ご確認ください |
| 受付でお聞きしてください | 受付でお尋ねください |
| ご利用してください | ご利用ください |
| 部長が申された | 部長がおっしゃった |
| 先方が参られます | 先方がいらっしゃいます |
| ご説明される（尊敬のつもり） | ご説明になる／説明される |

## 2. 二重敬語

同じ種類の敬語を一語に重ねたもの。

| 誤り | 正しい形 |
|---|---|
| おっしゃられる | おっしゃる |
| ご覧になられる | ご覧になる |
| お越しになられる | お越しになる |
| 拝見させていただく | 拝見する／拝見いたします |
| お伺いさせていただく | 伺います |

**習慣として定着し、許容されるもの**（直さなくてよい）：お召し上がりになる、お見えになる、お伺いする、お伺いいたします。気にする読み手がいる文書（役員向けなど）では、より簡素な形に寄せてもよい。

「〜いただけますでしょうか」は丁寧語を重ねた形で、二重敬語ではない。広く使われているので原則として直さない。

## 3. 「させていただく」

「敬語の指針」では、**相手の許可を得て行い、そのことで恩恵を受ける**場合に適切とされる。

- 適切：「本日は早退させていただけますか」（許可を求める）
- 過剰：「資料を送付させていただきます」→「資料を送付いたします」
- 過剰：「担当させていただいております山田です」→「担当の山田です」

一文書に3回以上あれば、許可・恩恵のない箇所を「〜いたします」「〜します」に戻す。

## 4. 接客・バイト敬語

| 表現 | 直し方 |
|---|---|
| こちら資料になります | こちらが資料です／でございます |
| よろしかったでしょうか | よろしいでしょうか |
| 資料のほうお持ちしました | 資料をお持ちしました |
| 〜円からお預かりします | 〜円お預かりします |

## 5. ビジネスメールの注意点

- 「お世話になっております」は冒頭に一回。
- 「御中」と「様」は併用しない。組織宛ては「御中」、個人宛ては「様」。
- 「各位様」は重複。「各位」だけでよい。
- 「部長様」のような役職＋様は重複とする見方が多い。「山田部長」または「部長の山田様」。
- 「ご教授ください」は学問・技芸を長く教わる意味。やり方を聞くだけなら「ご教示ください」。
- 「お体をご自愛ください」は重複。「ご自愛ください」だけでよい。
- 目上・社外への返事は「承知しました／かしこまりました」が無難。「了解しました」を失礼とする根拠は薄いが、気にする人がいるため避けるのが安全。誤りではなく配慮の問題として扱う。
- 目上への「ご苦労さまです」も同様に、「お疲れさまです」が無難。

## 6. 敬語の量

敬語は多いほど丁寧になるわけではない。一文に敬語が三つ以上重なったら、どれかを外して読みやすさを優先する。

- 過剰：「ご確認いただけましたら、ご返信いただけますと幸いに存じます」
- 適量：「ご確認のうえ、ご返信いただけると幸いです」

## 7. チャット（Slack・Teams）

社内チャットでは丁寧語を基本にし、尊敬語・謙譲語は最小限にする。毎回の「お疲れさまです」はチームの慣習に合わせる。要件を先に書く。
