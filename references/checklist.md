# 目視チェックリスト（Python が使えないとき）

上から順に一回だけ確認する。詳細は括弧内のファイル。

## ERROR（原則直す）
- [ ] 二重敬語：おっしゃられる、ご覧になられる、拝見させていただく（keigo.md）
- [ ] 相手の動作に謙譲語：ご確認してください、お聞きしてください（keigo.md）
- [ ] ら抜き：見れる、来れる、食べれる、起きれる
- [ ] さ入れ：休まさせていただく、読まさせていただく
- [ ] 文体の混在：です・ます と である が混ざっていないか
- [ ] 句読点の混在：「、。」と「，．」
- [ ] 半角カタカナ

## WARN（文脈で判断）
- [ ] 表記ゆれ：できる／出来る、すべて／全て、サーバ／サーバー など（hyoki.md）
- [ ] 全角英数字
- [ ] 80字を超える文（公用文・チャットは60字）
- [ ] 「させていただく」が3回以上
- [ ] 「することができる」「と言えるでしょう」「において」（ai-patterns.md）
- [ ] 「重要」「さまざまな」の3回以上の繰り返し
- [ ] 「よろしかったでしょうか」

## INFO（気になるものだけ）
- [ ] 読点が5個以上の文、60字超で読点のない文
- [ ] 「の」が4回以上続く名詞句
- [ ] 同じ文末が3文連続
- [ ] 「こちら〜になります」「〜のほう」
- [ ] 公用文・ビジネスで漢数字の数量（三件 → 3件）
