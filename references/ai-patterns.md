# AI調・翻訳調パターン

AIが書いた日本語には、一つひとつは誤りでなくても、積み重なると不自然になる癖がある。見つけても機械的に消さず、**なぜそこにあるか**を考えて直す。多くは「中身がない箇所を言い回しで埋めている」サインなので、具体的な情報を足すのが本当の直し方になる。

## 1. 言い回し

| よくある形 | 直し方 |
|---|---|
| 〜することができる | 〜できる |
| 〜と言えるでしょう／と考えられます（根拠なし） | 言い切る。迷うなら根拠を書く |
| 〜ではないでしょうか（主張なのに） | 〜です |
| 〜において | 〜で、〜の |
| さまざまな／多岐にわたる | 具体例を2〜3個挙げる |
| 重要です／不可欠です | なぜ重要か、何が起きるかを書く |
| 〜の鍵となる、紐解く、深掘りする | 普通の動詞で言う |
| 〜と言っても過言ではない | 削る |
| いかがでしたか／〜を見ていきましょう | 削って本題に入る |
| まさに、非常に、大変（多用） | 削る |

## 2. 演出・呼びかけの癖

内容ではなく「語り口」でAIらしさが出るもの。台本・ブログ・紹介文で特に目立つ。

| よくある形 | なぜ不自然か | 直し方 |
|---|---|---|
| コツは一つ。／理由はシンプルです。 | 答えの前に溜めを作るプレゼン調 | 前置きを削り、答えを直接書く |
| 〜するだけで、〜できます | 手軽さを誇張する広告の決まり文句 | できることを淡々と書く |
| 〜しましょう／〜してみましょう | 読み手に呼びかける教材調 | 「〜してください」か、言い切る |
| 〜なんです。〜なんですよね。 | 親しげさの演出 | 「〜です」 |

**リズムを短い決め台詞で作らない。** 文の長さに変化をつけたいときは、長すぎる文を分けるか、短い文同士をつなぐ。数値を満たすために「〜は一つ。」のような断片を差し込むと、かえってAI臭くなる。

## 3. 英語直訳の癖

| 直訳調 | 自然な日本語 |
|---|---|
| このツールは3つの機能を持つ | このツールには機能が3つある |
| 〜することを可能にする | 〜できるようにする |
| 最も重要なものの一つは | 特に大事なのは |
| 彼／彼女は（繰り返し） | 名前で書くか、主語を省く |
| それは〜だからです | 〜ためです |
| 〜によって作成された報告書 | 〜が作った報告書 |
| ユーザーに対して通知する | ユーザーに通知する |

## 4. 構造の癖（機械では見つけにくい）

- **何でも三点にまとめる**：実際は2つや4つのことを、3つに揃えていないか
- **見出しがラベル**：「背景」「課題」「まとめ」→ 見出しに結論を書く（「原因は設定値の桁誤り」）
- **全段落が同じ長さ・同じ構成**：大事な節は厚く、軽い節は短く
- **最後の「まとめ」が本文の繰り返し**：繰り返すなら、読み手が次にすべきことを書く
- **「AではなくB」の多用**：誰も思っていない誤解を否定していないか
- **太字・絵文字・コロン見出しの多用**：太字は一段落に一箇所まで
- **箇条書きで理由を書く**：理由・経緯は文章でつなぐ

## 5. 直すときの注意

- 固有名詞・引用・会話文の中は直さない
- 書き手の口癖（意図した個性）は残す
- 言い回しを消した結果、文が空っぽになったら、その文ごと削る
- 同じ置き換えを全箇所に当てない。「することができる」を全部「できる」に変えるように機械的に掃引すると、直した跡が均質に並んでそれ自体が不自然になる。目立つ箇所だけ直し、残りは文脈で判断する
